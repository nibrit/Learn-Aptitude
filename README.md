## 📖 About

This repository is a **curated, topic-wise collection** of aptitude problems, formulas, solved examples, and practice sets — organized for efficient preparation.

**Who is this for?**

- 🏢 Students preparing for **Campus Placements** (TCS, Infosys, Wipro, Accenture, Cognizant)
- 🎓 Aspirants targeting **GATE / CAT / GRE / GMAT**
- 🧪 Anyone clearing **online aptitude screening rounds**
- 📚 Self-learners wanting structured quant and reasoning practice

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/nibrit/Learn-Aptitude.git

# Enter the repo
cd Learn-Aptitude

# Browse topics
cd "Aptitude Topic wise"
```

**Recommended Study Workflow:**

```
1. 📖  Read theory and key formulas for the topic
2. 🔍  Study the solved examples carefully
3. ✏️  Attempt practice problems independently
4. ✅  Verify with solutions — note your mistakes
5. 🔁  Revisit weak topics every 3-4 days
```
