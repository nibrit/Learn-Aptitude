## 📖 About The Repository

<img align="right" src="https://media.giphy.com/media/LaVp0AyqR5bGsC5Cbm/giphy.gif" width="220" />

This repository is a **comprehensive, topic-wise collection** of aptitude problems — curated and organized to help you build strong foundations for:

- 🏢 **Campus Placements** (TCS, Infosys, Wipro, Accenture & more)
- 🧪 **Competitive Exams** (GATE, CAT, GRE, GMAT)
- 🎯 **Technical Interview Rounds**
- 🏆 **Placement Aptitude Tests (PAT)**

Each topic folder contains **theory notes**, **solved examples**, **practice problems**, and **shortcut formulas** — making it easy to learn, revise, and master.

## 🚀 How To Use

```bash
# 1. Clone the repository
git clone https://github.com/nibrit/Learn-Aptitude.git

# 2. Navigate into the folder
cd Learn-Aptitude

# 3. Browse topic-wise folders
cd "Aptitude Topic wise"

# 4. Open any topic, study notes, and solve problems!
```

**Recommended Workflow:**
1. 📖 Read the theory/formulas for a topic
2. 🔍 Study the solved examples
3. ✏️ Attempt the practice problems on your own
4. ✅ Verify with solutions & identify gaps
5. 🔁 Revise weak areas periodically
